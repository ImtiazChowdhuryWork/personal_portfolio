📌 How to get your App Password from Google: 1. Go to myaccount.google.com and sign in with the Gmail you want to send from
2. Click Security in the left sidebar
3. Make sure 2-Step Verification is turned ON
4. Search "App passwords" at the top and open it
5. Type a name (e.g. Portfolio) → click Create
6. Google shows a 16-character password — copy and paste it into the 4 boxes above
⚠ Google only shows this password once. Save it here immediately — you cannot view it again later.
